Luv Michael · Step Station (bracelet)
=====================================

双击打开（先解压，不需要安装）:
  StepStation_mockup_v11.html  - 3D 模型。打开时桌面是空的：点底部的步骤卡，每点一次出现一个部分（渐显）。
    右上角 Controls → Replay guide 可重播；网址加 ?guide=0 直接显示全部。步骤：
    1 名字立牌放在桌子最远端，名字朝外给老师看  2 情绪量表（1–5）：把 Me 放到对应的一行  3 点 Start box 摆出珠子
    4 横版活页（左侧装订）：一页一个步骤、5 张小图，做完在左侧页标签贴 ✓  5 做好的手链放进 Finish box
    ★ 任何时候：把双面卡插进左边的透明亚克力立牌： I'm OK / Help / Break（虚线框区域）
    右上角 Controls 里可以隐藏标签、看使用说明。
  Step_Card_Maker.html        - 卡片生成器。填步骤、传照片、列珠子顺序，点 Print 打印。
